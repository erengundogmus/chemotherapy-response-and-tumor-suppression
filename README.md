# TA3 Chemotherapy Response and Tumor Suppression

This repository is developed for the SENG 495 Senior Graduation Project.

The project is based on the study "Physics-Informed Neural Network for Parameter Inference in a Tumor Model" by Kisbenedek et al. Our first goal is to understand the reference implementation and use it as the starting point for our own experiments.
